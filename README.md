# Progress Component

Прототип переиспользуемого блока Progress для мобильных web-приложений на чистом JS/CSS/HTML

## Демо

[Открыть демо на GitHub Pages](https://annssva.github.io/test-progress-component/)

## Возможности

Компонент отображает круговой прогресс и поддерживает три состояния:

- **Normal** — базовое состояние, значение `Value` (0–100) определяет длину дуги. Начало дуги — 12 часов, конец движется по часовой стрелке при увеличении значения.
- **Animated** — независимое состояние вращения компонента.
- **Hidden** — полностью скрывает блок со страницы.

Все три состояния независимы друг от друга и могут комбинироваться.

## API компонента

```js
const progress = ProgressComponent.create(element, initialValue);

progress.setValue(value);   // присвоить значение (number от 0 до 100, невалидные значения игнорируются)
progress.getValue();        // получить текущее значение

progress.setAnimate(bool);  // включить/выключить анимацию вращения
progress.getAnimate();      // получить текущее состояние

progress.setHidden(bool);   // показать/скрыть блок
progress.getHidden();       // получить текущее состояние
```

`setValue` не изменяет состояние при передаче некорректного значения (не число, `< 0`, `> 100`), валидация полностью на стороне компонента, что защищает его от некорректного использования независимо от UI.

## Демо-приложение

Реализованы три элемента управления:

- **Value** — текстовый ввод, во время набора допускаются только цифры, значение живо синхронизируется с дугой, на blur/Enter значение и отображение в поле финально приводятся к диапазону 0–100.
- **Animate** — переключатель состояния анимации.
- **Hide** — переключатель состояния скрытия компонента.

Приложение адаптируется под ориентацию экрана (`orientation: portrait`/`landscape`).

## Дополнительные технические решения

- **Стили и логика в отдельных файлах** `progress-component.css` и `progress.js` подключаются вручную. 
- **Резервирование места под компонент при Hidden** сделано специально на уровне демо-приложения (`.app-progress-wrapper`), чтобы интерфейс не съезжал при скрытии компонента прогресса, сам клмпонент скрывается с помощью `display: none`
- **Валидация значения сделана на двух уровнях:** в UI-инпуте для приятного UX при вводе и в самом API компонента для строгой защиты.
- Значение округляется до целого — дробный прогресс не поддерживается.
- При некорректном начальном значении (`< 0`, `> 100`, `NaN`) компонент стартует с пустой дугой.

## Запуск локально

Открыть `index.html` в браузере.

## Использование в другом проекте

1. Скопируйте `css/progress-component.css` и `js/progress.js` в проект.
2. Подключите оба файла на странице:
```html
<link rel="stylesheet" href="progress-component.css">
<script src="progress.js"></script>
```
3. Создайте контейнер и инициализируйте компонент:
```html
<div id="my-progress"></div>
```
```js
const progress = ProgressComponent.create(
    document.querySelector('#my-progress'), // селектор контйенера
    50 // начальное значение, необязательно
);

progress.setValue(80);
progress.setAnimate(true);
progress.setHidden(false);
```

Компонент занимает 100% ширины и высоты своего контейнера, задайте контейнеру нужные размеры через CSS.
